§ 03

新建虚拟机（分步图解）

打开 VirtualBox，点击工具栏「新建」或菜单「控制 → 新建」，进入向导。

图3 · 初次启动的 VirtualBox 控制台（尚无虚拟机）
  1. 填写名称与系统类型
    名称：LEARN-ASM  ·  操作系统：Other  ·  版本：Other/Unknown
    图4 · 填写名称，操作系统选 Other / Other/Unknown
  2. 设置内存大小
    默认建议值即可（示例：64 MB）；拖动滑块调整。内存大小对汇编学习影响不大。
    图5 · 调整内存容量
  3. 配备虚拟硬盘
    有两种方式，优先推荐方式 A：
    方式 A（推荐）：直接使用 LEECHUNG.VHD
    解压配书工具包，选「使用现有的虚拟硬盘」→ 浏览找到 LEECHUNG.VHD，选中后直接跳到步骤 7。
    方式 B：自行新建 VHD
    选「创建新的虚拟硬盘」→ 点「下一步」，继续步骤 4–6。
    图6 · 选择创建新盘或使用现有盘
  4. 选择虚拟硬盘格式：必须选 VHD
    ⚠️ 只能选 VHD
    配书工具 FixVhdWr 只支持 VHD 格式。VDI（VirtualBox）、VMDK（VMware）、HDD（Parallels）均不兼容，不要选。
    图7 · 文件类型选 VHD（Virtual Hard Disk）
  5. 存储方式：必须选 Fixed size
    ⚠️ 只能选 Fixed size
    本书及配套工具仅支持固定尺寸 VHD。不要选 Dynamically allocated。
    图8 · 存储方式选 Fixed size
  6. 指定容量与位置
    容量 ≥ 50 MB（建议 100–200 MB）。
    位置改到配书工具所在文件夹（默认放在用户目录，不易找到）。
    图9 · 指定容量（≥50 MB）与保存位置
  7. 完成向导
    LEARN-ASM 出现在控制台左侧。暂不要点「开始」——虚拟硬盘尚为空，需先用配书工具 FixVhdWr 写入引导程序。
    图10 · 创建完成，LEARN-ASM 出现在控制台
§ 04

VHD 虚拟硬盘结构说明

固定尺寸 VHD 是一个 .vhd 文件，结构只有两部分：

数据区
每扇区 512 字节，顺序对应物理硬盘扇区：
0面0道1扇区 → 0面0道2扇区 → … → 0面0道n扇区（n = 每道扇区数）→ 1面0道1扇区 → … 按柱面依次排列。
文件尾 512B
以 "conectix" 开头（VHD 格式的原始创建者标识），后跟：创建日期、VHD版本、创建程序名称/版本/所属OS、磁头数、每面磁道数、每磁道扇区数、VHD类型、虚拟硬盘总容量。
图11 · HexView 查看 VHD 文件尾，可见 "conectix" 标识

硬盘读写规则

访问硬盘需提供：磁头号、磁道号、扇区号、读写意图。最小操作单位为 1 个扇区（512 字节），数据不足时须用无意义字节填充至 512 字节。

固定尺寸 vs 动态分配

类型文件大小本书支持
Fixed size（固定尺寸） 等于虚拟硬盘容量，一次分配（2 GB VHD = 2 GB 文件） 支持 ✓
Dynamically allocated（动态） 随写入量增长，初始较小 不支持 ✗
