Windows 系统操作指南 · 本地账户

用户名重命名完整操作步骤

适用于 Windows 10 / Windows 11 本地账户 · 两种方法可选
洪亮若西 → 长河落日
⚠ 操作前须知： 两种方法均需创建临时管理员账户，用于在不占用目标账户的情况下操作文件夹与注册表。请按顺序执行，勿中途强制重启。
方法一：命令行（CMD）方式
01
重命名账户名称（wmic）
登录：洪亮若西

以管理员身份运行 CMD，执行命令将账户名改为「长河落日」：

管理员 CMD
wmic useraccount where name='洪亮若西' rename '长河落日'
✓ 显示「执行成功」即可。此步只改账户名，用户文件夹暂未变动。
02
创建临时管理员账户
登录：洪亮若西
管理员 CMD
:: 创建临时账户
net user TempAdmin MyPass123 /add
:: 加入管理员组
net localgroup administrators TempAdmin /add
03
注销，切换 TempAdmin 登录
登录：TempAdmin

必须切换账户，否则用户文件夹被占用无法改名。

操作
Win + L  →  切换用户  →  选择 TempAdmin 登录
04
重命名用户文件夹
登录：TempAdmin
管理员 CMD
ren C:\Users\洪亮若西 长河落日
✓ 第二个参数只写新名字，不需要写完整路径。
05
修改注册表 ProfileImagePath
登录：TempAdmin

按 Win+R 输入 regedit，导航到：

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList

展开后逐个点击 S-1-5-21-... 子项，找到右侧 ProfileImagePath 为旧路径的项，双击修改：

注册表修改
ProfileImagePath：C:\Users\洪亮若西  →  C:\Users\长河落日
06
重新登录长河落日，验证并清理
登录：长河落日

注销 TempAdmin，切换回「长河落日」登录，在 CMD 中确认：

预期结果
C:\Users\长河落日>_
✓ 确认正常后删除临时账户：net user TempAdmin /delete

方法二：netplwiz 图形界面 + 补充说明

洪亮若西 → 长河落日
方法二：netplwiz 图形界面方式
说明：netplwiz 可完成账户名重命名（对应方法一的步骤01），文件夹改名与注册表修改仍需手动完成（同方法一步骤02～06）。
① 用 netplwiz 重命名账户
  • 1
    按 Win+R，输入 netplwiz，回车
  • 2
    在「用户」标签下，选中账户 洪亮若西
  • 3
    点击「属性」按钮
  • 4
    在「用户名」栏将 洪亮若西 改为 长河落日
  • 5
    点「确定」→「应用」，关闭窗口
✓ 完成后账户名已改，继续执行下方步骤②③④
② 创建临时管理员账户
  • 1
    按 Win+R，输入 netplwiz，回车
  • 2
    点「添加」→「不使用 Microsoft 账户登录」
  • 3
    选「本地账户」，填写用户名 TempAdmin 及密码
  • 4
    添加完成后，选中 TempAdmin → 点「属性」→「组成员」→ 选「管理员」
③ 重命名文件夹（TempAdmin 登录后）

注销「长河落日」，用 TempAdmin 登录后，以管理员 CMD 执行：

管理员 CMD
ren C:\Users\洪亮若西 长河落日
④ 修改注册表

按 Win+R 输入 regedit，导航到：

HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList

找到 ProfileImagePath 值为旧路径的子项，修改为：

修改值
C:\Users\长河落日
✓ 完成后注销 TempAdmin，重新用「长河落日」登录验证
操作顺序总览（两种方法对比）
步骤 操作内容 方法一（CMD） 方法二（netplwiz） 当前登录
01 重命名账户名称 wmic useraccount rename netplwiz → 属性 → 改用户名 洪亮若西
02 创建临时管理员 net user TempAdmin /add netplwiz → 添加 → 本地账户 洪亮若西
03 切换 TempAdmin 登录 Win+L → 切换用户 TempAdmin
04 重命名用户文件夹 ren C:\Users\洪亮若西 长河落日 TempAdmin
05 修改注册表 ProfileImagePath regedit → ProfileList → 改路径 TempAdmin
06 验证 + 删除 TempAdmin net user TempAdmin /delete 长河落日
