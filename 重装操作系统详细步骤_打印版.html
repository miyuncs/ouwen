1
准备一个大容量 U 盘（或移动硬盘）

建议容量 16 GB 以上（Windows 10/11 镜像约 5–6 GB，留出余量）。移动硬盘同样适用，下文统称 U 盘。

⚠购买建议：电子产品尽量选择京东自营渠道购买国际大牌产品（如闪迪、三星、金士顿），避免淘宝或京东第三方卖家，质量与售后更有保障。
2
格式化 U 盘（可选，按需操作）

若 U 盘内数据无需保留，可先格式化；若有重要内容，在 U 盘内新建文件夹备份后再操作。

操作方式

打开「此电脑」，右键点击 U 盘图标 → 选择「格式化」，出现如下界面：

▲ Windows 格式化对话框

文件系统（File System）选择

▲ 文件系统选项
格式跨平台单文件限制适用场景
FAT32Windows / macOS / Linux最大 4 GB小文件通用传输
exFATWindows / macOS / Linux无限制大文件跨平台（推荐）
NTFS仅 Windows（macOS 只读）无限制纯 Windows 环境
💡若 U 盘需要在 Mac / Linux 上使用，请选择 exFAT；若只在 Windows 环境使用，NTFS 也可。系统镜像（.iso）超过 4 GB，不要选 FAT32。

分配单元大小（Cluster Size）详解

▲ 分配单元大小设置

分配单元大小（Allocation Unit Size），又叫簇大小（Cluster Size），是文件系统管理磁盘空间的最小单位。磁盘不是按字节逐一分配的，而是把空间切成固定大小的「格子」（簇），每次分配至少给一个格子。

📦举例：分配单元大小为 4 KB，存入一个 1 KB 的文件 → 系统分配 4 KB 的簇给它，其中 3 KB 被浪费（称为「内部碎片」）。
小簇（512B / 1KB / 2KB）大簇（16KB / 32KB / 64KB）
空间利用率高，小文件浪费少低，小文件浪费多
读写速度稍慢（寻址次数多）稍快（大块连续读写）
适合场景文档、代码等小文件视频、系统镜像等大文件

U 盘怎么选？

一般用途：直接使用 Windows 默认值（FAT32/exFAT 下通常为 4KB 或 32KB），无需更改。

存大视频 / 系统镜像：可选 32KB 或 64KB，传输稍快。

存大量小文件（代码、文档）：选 4KB，节省空间。

「卷标」即 U 盘的名称，一般采用默认值即可。建议勾选快速格式化以加快速度。

3
备份计算机重要资料到 U 盘

格式化系统盘前，务必将重要数据转移到 U 盘或移动硬盘。

3.1 · 用户个人文件

C:\Users\用户名\ 目录下的所有个人资料（文档、图片、下载等）。

3.2 · C 盘其他位置

检查 C 盘根目录，如 C:\个人资料\ 之类自建文件夹。重装后 C 盘会被格式化，务必不遗漏。建议养成习惯：个人资料不存系统盘（C 盘），放在 D 盘或其他分区。

3.3 · 是否全盘格式化

若怀疑其他盘分区含病毒、想全盘清除，则其他分区的重要资料同样需备份。

3.4 · 双重备份原则

备份到 U 盘后，建议再将 U 盘内容同步到另一台电脑或第二个 U 盘。大容量写入会导致 U 盘发热，存在因温度过高损坏的风险，单一备份不够安全。

3.5 · 验证备份完整性

格式化前打开 U 盘，随机抽查几个文件确认可以正常打开，防止备份过程中发生静默错误。

4
下载操作系统镜像文件

以 Windows 为例，推荐从权威渠道下载正版镜像。

4.1 · 安装迅雷

访问 xunlei.com 下载并安装迅雷，用于通过 ED2K 链接高速下载镜像。

4.2 · 获取镜像下载链接

访问 https://next.itellyou.cn，选择所需操作系统版本。

✅推荐版本：Windows 10 Enterprise LTSC 2021 (x64) – DVD (Chinese-Simplified)。该版本精简、稳定、长期支持，无多余预装应用，适合干净安装。尽量避免 Windows 11（对硬件要求更高，部分旧设备不兼容）。

找到对应版本后，点击 ED2K 链接旁的「复制」，迅雷会自动弹出下载对话框，选择保存位置即可。下载完成后，可在迅雷「已完成」列表中右键 → 「打开文件夹」定位文件。

5
下载并使用 Rufus 制作 USB 启动盘

访问官方网站 rufus.ie 下载 Rufus。不要用百度搜索，搜索结果多为非官方镜像站，存在安全风险。

5.1 · 以管理员身份运行

右键单击 Rufus.exe → 选择「以管理员身份运行」。插入 U 盘后界面如下：

▲ Rufus 启动后自动识别 U 盘设备

「设备」下拉框显示当前插入的 U 盘名称及容量。「引导类型选择」无需手动更改——点击右侧「选择」，找到并单击下载好的 .iso 镜像文件，Rufus 会自动填充引导类型。

5.2 · 镜像选项
▲ 镜像选项与分区设置

标准 Windows 安装：将操作系统安装到计算机硬盘（常规选择）。

▲ Windows To Go 选项

Windows To Go：将操作系统安装到 U 盘本身随身携带运行。需要 U 盘散热好、读写速度快（如 USB 3.2 Gen 2 固态 U 盘），普通 U 盘不建议此选项。

5.3 · 分区类型详解：UEFI / GPT / MBR / BIOS

这几个概念来自两个不同维度，理清关系就全明白了：

固件（旧）
BIOS

主板上最古老的固件程序，电脑开机第一个运行。负责检测硬件、寻找硬盘引导程序。界面为纯文字蓝屏，只能键盘操作。

⚠ 只支持 MBR 硬盘启动；不支持超过 2TB 的硬盘
固件（新）
UEFI

BIOS 的现代替代品，2010 年后的主板基本都是 UEFI。图形界面、支持鼠标、安全启动（Secure Boot）、启动更快。

✅ 支持 GPT，支持超过 2TB 的硬盘
分区表（旧）
MBR

1983 年的老式硬盘分区表格式。分区信息写在硬盘最开头的 512 字节里。

分区表（新）
GPT

MBR 的继任者，现代标准。有备份分区表，更安全可靠。

配套关系

主板固件          硬盘分区表
  BIOS    ──→     MBR       ✅ 传统组合（老电脑）
  UEFI    ──→     GPT       ✅ 现代标准组合
情况推荐选择
2012 年后的电脑UEFI + GPT（现代标准）
老电脑 / 旧主板BIOS + MBR（兼容性优先）
硬盘超过 2TB必须选 GPT，MBR 无法正确识别
✅一句话总结：现代电脑直接选默认的 GPT + UEFI 即可。
5.4 · 开始写入

确认设置后点击「开始」，Rufus 自动将镜像写入 U 盘并制作为可引导启动盘。

⚠写入过程中会清空 U 盘所有数据，请确认 U 盘内重要文件已另行备份。
6
从 U 盘启动计算机

将制作好的 USB 启动盘插入计算机。

6.1 · 进入 BIOS / UEFI 设置界面

开机时连续按下对应按键进入 BIOS（不同品牌主板按键不同，常见为 F2 / F8 / F10 / F12 / Del，请根据主板品牌自行查询）。

进入后找到 Boot（启动）相关选项，如 Boot Order 或 Boot Priority，将 USB 设备调整为第一启动项，保存并退出（通常按 F10 保存）。

💡部分主板支持开机时按 F12 直接弹出一次性启动菜单，选择 USB 设备即可，无需更改 BIOS 启动顺序。
7
安装操作系统
7.1 · 进入安装界面
▲ Windows 安装程序启动界面

选择语言、时间格式、键盘输入法后，点击「下一步」→「现在安装」。若下一步按钮灰色不可点击，先勾选「我接受许可条款」。

7.2 · 选择安装类型

选择「自定义：仅安装 Windows（高级）」，进入磁盘分区界面。

▲ 磁盘分区与新建界面（注意：单位为 MB）

点击「新建」，在大小框输入 C 盘容量（注意单位是 MB）：

📐1 GB = 1024 MB。若想设置 C 盘为 100 GB，输入 102400。若想设置 150 GB，输入 153600。

点击「确定」后，安装程序会自动创建若干系统保留分区（EFI 分区、MSR 分区等），这是正常现象。

7.3 · 继续分区
▲ 已创建 C 盘分区，剩余空间为「未分配」

左键选中「未分配的空间」，可继续点击「新建」将剩余空间划分为一个或多个分区（如 D 盘、E 盘）。

7.4 · 选择安装分区（重要）
▲ 注意：安装程序可能自动选中最后创建的分区
⚠特别注意：分区完成后，安装程序会自动高亮最后创建的分区，而非你想要的 C 盘目标分区。请手动点击正确的目标分区，再点击「下一步」，否则操作系统将被安装到错误分区。
7.5 · 等待安装完成，完成初始设置

耐心等待安装程序复制文件、自动重启数次后，进入 Windows 初始设置界面。

▲ Windows 初始设置 · 账户登录界面
✅在账户设置页面，选择「改为域加入」（或「脱机账户」），可创建本地账户而无需登录微软账号。输入用户名、密码及密码提示问题后，按提示完成隐私选项设置，系统安装即告完成。
8
激活 Windows

安装完成后，Windows 处于未激活状态，部分功能受限（如无法自定义壁纸、系统设置右下角持续显示「激活 Windows」水印）。激活的本质是向微软服务器验证你的许可证有效性。

为什么需要激活？

Windows 是商业软件，微软以许可证方式授权使用。安装镜像本身是公开的，但使用权需要通过激活来验证。未激活的系统功能上可以正常使用，但会有水印提示，且无法获得完整的系统更新支持。

使用 KMS（Key Management Service） 是企业和学校批量激活 Windows 的标准机制——微软官方支持的激活方式。原理是让系统连接到一台 KMS 服务器，由服务器颁发 180 天的激活授权，每隔一段时间自动续期，只要服务器在线就持续有效。

💡KMS 激活的原理：你的电脑向 KMS 服务器发送激活请求 → 服务器验证并颁发 180 天授权 → 系统在到期前自动联网续期。只要 KMS 服务器持续运行，激活就一直有效。

激活步骤

8.1 · 以管理员身份打开命令提示符

按 Win + S 搜索「cmd」，右键点击「命令提示符」→ 选择「以管理员身份运行」。必须以管理员身份运行，否则命令无权限执行。

8.2 · 设置 KMS 服务器

在命令提示符中输入以下命令，按回车执行：

slmgr /skms kms.03k.org

此命令将 KMS 服务器地址设置为 kms.03k.org。执行成功后会弹出提示框显示「密钥管理服务计算机名成功地设置为 kms.03k.org」。

8.3 · 执行激活

继续输入以下命令，按回车执行：

slmgr /ato

此命令让 Windows 立即向 KMS 服务器发起激活请求。激活成功后弹出提示框显示「成功地激活了产品」。

✅验证激活状态：激活完成后，可执行 slmgr /xpr 查看激活到期时间；或进入「设置 → 系统 → 关于」，确认显示「Windows 已激活」。
⚠若提示激活失败，检查网络连接是否正常，或稍后重试。KMS 激活需要联网，离线状态下无法完成。
